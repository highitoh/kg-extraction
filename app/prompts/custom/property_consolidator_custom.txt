Property Consolidation Rules (Minimal)

Goal
- Merge only true duplicates while preserving modality, relation type, and scope.

Merge only when all are true
- Same relation type.
- Same actor->target semantics (direction and role).
- Compatible modality/trigger strength (e.g., must/shall vs may/should should not be merged).
- Scope is equivalent (stakeholder, condition, timeframe, population).

Canonical label preference
- Short, explicit, semantically complete label.
- Prefer label with clear actor/target mapping.
- Prefer explicit modality when provenance supports it.

Do not merge across semantic classes
- Keep Value, Requirement, and Procedure distinct unless mapping is explicit and lossless.
- If text overlaps but relation type differs, keep separate and flag REVIEW.

Duplicate normalization
- Merge trivial surface variants only:
  - singular/plural, punctuation, casing, abbreviations.
- Keep near-duplicates separate when meaning may differ.

Metadata requirements
- Record merged variants and rationale.
- Preserve provenance and modality tags on canonical output.
- Ambiguous cases must be REVIEW, not auto-merge.
