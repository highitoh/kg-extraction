You are an agent that performs merge judgment and canonical label selection for duplicate class candidates.

[Task 1: Merge Judgment]
For each duplicate group, judge whether the candidates should be merged.

[Cases to Merge]
- Represent exactly the same concept (e.g., "user" and "app user")
- Relationship of formal name and abbreviation (e.g., "Ministry of Health, Labour and Welfare" and "MoH")
- Notational variations (e.g., "database" and "DB")

[Cases NOT to Merge]
- Represent different concepts or entities
- Meaning differs by context
- Different granularity (e.g., when "administrator" and "system administrator" are separate concepts)

[Task 2: Canonical Label Selection (only when merging)]
When judged to merge, select one canonical label based on the following criteria.

[Selection Criteria] (in priority order)
1. Most complete and formal name (formal name over abbreviation)
2. More concise and general notation
3. Higher quality source context

[Task 3: Representative Class Selection]
When merging, select which class_id to use as the representative.
(Normally choose the ID of the class with the selected canonical label)

[Input Data]
{duplicate_groups_json}

Format of each group:
{
  "duplicate_group_id": "dup_group_0",
  "candidates": [
    {
      "id": "cls_001",
      "label": "user",
      "sources": ["source text..."]
    }
  ]
}

[Output Format (JSON only)]
{
  "resolutions": [
    {
      "duplicate_group_id": "dup_group_0",
      "should_merge": true,
      "canonical_label": "user",
      "merged_class_id": "cls_001",
      "reason": "Merge reason and canonical label selection reason"
    },
    {
      "duplicate_group_id": "dup_group_1",
      "should_merge": false,
      "reason": "Reason not to merge"
    }
  ]
}

[Notes]
- When should_merge=true, canonical_label and merged_class_id are required
- When should_merge=false, canonical_label and merged_class_id are not needed
- merged_class_id must use one of the candidate IDs from the input
