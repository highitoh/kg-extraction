## Strength Evaluation Criteria

Evaluate the strength of each relationship on the following 4-level scale:

### 3 / Strong (Essential Dependency)
**Meaning:** A cannot exist without B
**Examples:**
- "Authentication System" and "User Database" (authentication system cannot function without user database)
- "Payment Function" and "Credit Card Information" (payment function cannot exist without credit card information)

### 2 / Medium (Functional Dependency)
**Meaning:** A's efficiency/performance improves when using B
**Examples:**
- "Search Function" and "Index" (search becomes faster with an index)
- "Report Generation" and "Cache Mechanism" (processing becomes more efficient with cache)

### 1 / Weak (Environmental Dependency)
**Meaning:** B is desirable but alternative means exist without it
**Examples:**
- "System" and "Monitoring Tool" (system operates without monitoring tool)
- "Application" and "Log Collection Service" (functions execute without logs)

### 0 / None (No Relationship)
**Meaning:** Logically independent or relationship is incorrect
**Examples:**
- "User Registration Function" and "Weather Forecast Data" (logically independent)
- Clearly incorrect relationships

## Output Format

For each relationship candidate, output a JSON object containing the following information:

```json
{{
  "relations": [
    {{
      "src_id": "Source class ID",
      "dest_id": "Destination class ID",
      "strength": integer value 0-3,
      "justification": "Basis for strength evaluation (1-2 sentences)"
    }}
  ]
}}
```

## Evaluation Guidelines

1. **Prioritize class definitions**: Refer to class definition statements, not just labels, to understand the essence of relationships
2. **Reference instance labels**: Read specific context from each instance's label
3. **Consider dependencies**: Evaluate the degree to which the source depends on the destination
4. **Keep justification concise**: Clearly describe the basis for evaluation in 1-2 sentences

Evaluate and output all relationship candidates.
